## Overview

OpenMW is a fully open-source reimplementation of Bethesda's Morrowind game engine, enabling The Elder Scrolls III to run natively on modern Linux, macOS, and Windows with improved stability, bug fixes, and extended modding capabilities. It supports the original Morrowind game data plus fan-made total conversions and is the reference engine for the active Morrowind modding community.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **OpenMW** delivers the features you need in a clean, intuitive package.

> Official website: [openmw.org](https://openmw.org)

## Key Features

| Feature | Description |
|---------|-------------|
| **Native Ports** | Runs natively on Linux, macOS, and modern Windows without Wine |
| **Original Data** | Compatible with Morrowind, Tribunal, Bloodmoon, and all official plugins |
| **Engine Fixes** | Fixes hundreds of bugs and limitations present in the original engine |
| **Mod Support** | Supports all Morrowind mods and serves as base for total conversion projects |
